# Purlay — Decision record

> **Status:** Approved 2026-09-07. Amended 2026-09-09 (D-25 – D-53; D-1, D-24 and D-28 rewritten when the product
> gained a cloud offering). Binding. Split into one file per decision on 2026-11-26 (D-345); the numbers and the
> words of every decision are the ones the single `DECISIONS.md` had.
> This record is the SSOT for *why*. `PRD.md` says what, `ARCHITECTURE.md`/`SCHEMA.md` say how.

Legend: **D-n** = decision. Each records the choice, the reason, what was rejected, and the cost of reversing it
later. Questions still open, and the decisions that closed the earlier ones, are in
[`open-questions.md`](open-questions.md).

## Finding a decision

Each decision is one file, `<category>/D-<n>-<a-few-words>.md`, headed `# D-<n>. <title>`. The tables below list
every one by category with the day it was decided and the decisions that later amended it. A citation such as
"D-207" in code or in another document means the file whose name starts `D-207-`: search for it, or find it in the
table.

From D-203 on, decisions were numbered after the first release; a decision that changes an earlier one says so in its
title (`amends D-n`) and the earlier one carries a note that points back.

## Recording a decision

1. `bun run decision:new <category> <title>` makes the next number's file from [`_template.md`](_template.md) in its
   category and updates the index. The categories are the headings below.
2. Write it as the template asks: what was decided and by whom, why, what was rejected, and the cost of reversing.
3. If it changes an earlier decision, end its title with `— amends D-x` and add under D-x's title the line
   `*Amended by D-<n>: what changed.*`
4. Cite it where it acts (the document or code it governs): a decision nothing cites is either not propagated or dead.
5. `bun run check:docs` holds all of this, and that the index below is what the files say
   (`bun run decisions:index` rewrites it).

A decision is never renumbered, moved between numbers or deleted; one that stopped being true is amended by a later
one. Moving a file to another category is fine: its number is its name.
