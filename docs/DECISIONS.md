# Purlay — Decision record

The decision record is no longer one file. Since 2026-11-26 each decision is a file of its own in
[`decisions/`](decisions/README.md), indexed by category; the open questions are in
[`decisions/open-questions.md`](decisions/open-questions.md) (D-345).

A citation such as "`DECISIONS.md` D-207" in code or another document means the decision whose file name starts
`D-207-`: its number is unchanged, and the [index](decisions/README.md) lists every one.
