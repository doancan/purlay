# Purlay v0.6.3 — 2026-11-11

### Fixed

- **Notifications** — Missed-message email resumes after a worker restart, keeping earlier unsubscribe links valid and rechecking current access before retry (D-302).

- **Reconnect** — A channel archived while disconnected shows its archived reason even when HTTP refresh arrives before the socket reconnects. Delayed replies cannot restore pending sends or finish a later membership loss (D-303).

### Maintenance

- **CI** — Browser tests use a pinned browser image, avoiding the repeated Ubuntu package-mirror failures during installation. Test coverage, visual baselines and performance limits stay enforced (D-304).
